## E-20261107-04｜从“十条满淘汰”转为可恢复的消息契约
- 类型：决策 / 故障预防 / 验证。
- 背景：初始需求允许十条积压；审查发现满队列丢旧消息、入库后发送超时引发重复、业务成功但 ACK 失败重放、同步推送拖慢响应四类风险。用户 #68 授权修复高及以上四项。
- 行动：队列满事务内返回 409、不淘汰；`sender + clientMessageId` 收据与入队同事务，HMAC 绑定接收方/正文，ACK 后保留 7 天、每发送方最多 10000 条；接收示例把业务 SQLite 写入和 processed ID 同事务，再 ACK；提交后用 2 个固定推送协程合并接收方通知，避免每消息无限建 task。
- 结果：源码确认这些机制存在；历史验收报告覆盖十条边界、幂等冲突、ACK、慢推送、去重重启/回滚。SDK 另有代际隔离、超时与串行处理的生命周期补强。
- 证据：聊天 #58/#59/#68/#69；`server.py:47–67,425–484`；`integration/reliable_receiver.py`；`test_hub.py` 的 reliable_send；`消息转发稳定性审查.md` 最后一节。
- 贡献边界：用户明确优先级与修复范围；方案细化、代码和测试主要由 AI 执行。接入业务仍须实现持久 outbox/inbox，服务器升级不等于客户端自动可靠。
- 限制：不承诺全局 exactly-once；第三方副作用不与本地 SQLite 原子提交；无生产故障演练或压测。根 README 仍写“尾部淘汰”，属过期说明，本次仅记录冲突、不改原文。

- 结果：当前更新器含 `readable_application()` 与 `verify_pages()`；旧文档报告本地语法/文档测试通过，Windows 无法完整重验 Linux root/service-user 权限。

## E-20261107-07｜从转发 JSON 到可授权、可过期的业务信封
- 类型：决策 / 安全边界。
- 背景：用户询问 token 存放、数据/指令区分，并要求四种业务类型与标准约束；同时要求凭据可轮换并以掩码区分。
- 行动：业务分类放在 `body.kind`（data/event/command/result），不改变外层转发身份；v1 包含 operationId、时间和 payload，command 必须带 expiresAt，失败结果带结构化 error。声明协议的明文由服务端校验，旧 JSON 保持兼容；E2E 则需端点解密后再校验。
- 安全取舍：格式校验不等于授权；接收方仍校验真实外层 sender、命令白名单、每命令 payload 和有效期；ACK 不等于业务完成，另发 result。token 仅一次返回完整值，数据库保存摘要和用于展示的末三位；轮换断开旧 WS，不删除待收队列。
- 证据：聊天 #74—79；`integration/business_protocol.py`、`business-protocol.mjs`、`hub-sdk.mjs`；`server.py` 的 rotate_token；`test_hub.py:test_04b_token_rotation`。
- 贡献边界：用户提出协议/显示要求，AI 提出具体信封并实现；未证实真实跨设备客户端均已采用新协议。
- 限制：协议不是通用远程代码执行器；不能把 token 硬编码到公开代码当作安全方案。截图监听与笔记导入仍未实现。

## E-20261107-08｜“下载完即删”改为接收端可靠保存后确认
- 类型：需求澄清 / 数据生命周期决策。
- 背景：用户要求截图/大文件放在隐藏 `.file`、云盘不显示、下载后删除。若按 GET 结束就删，断网或本地写失败可能丢失唯一副本。
- 行动：附件独立于云盘表，放在非公开数据目录，随机文件名、分块 AES-GCM；接收端下载后核对 SHA-256/大小，临时落盘、文件 fsync、重命名后才 `/complete`。确认失败保留本地文件并重试确认，而非再次导入。服务端先写 deleted 墓碑再删文件，失败留待清理；有过期、配额与上传幂等键。
- 结果：源码有对应生命周期与角色检查；历史交付报告鉴权、错误确认不删、重复确认、过期/取消清理等通过。
- 证据：聊天 #80/#81；`relay_attachments.py`；`integration/attachment-client.mjs`；`test_attachments.py`、`test_attachment_client.mjs`；`临时附件前置工程.md`。
- 贡献边界：用户规定存储/删除需求，AI 细化确认协议并实现；这是前置模块，不是已打通的平板笔记产品。
- 限制：点号隐藏不是安全措施；删除不是介质安全擦除；未测真实平板、Nginx 大文件、慢网络或断电持久性。文件 fsync + rename 不等同所有平台上经过断电验证的持久化保证。
