# 前端体验更新（2026-11-06）

保留深绿 / 荧光绿视觉，新增原创本地 SVG 门户插画，无外部图片、字体或 CDN 请求。

云U盘新增：全局路径关键词搜索、文件夹优先排序（名称/上传时间/大小）、可点击面包屑、列表/网格、选择/批量删除、自定义新建与删除对话框、顺序上传队列/进度/失败重试、空间用量、移动端适配。

新增单项与批量移动（含子目录）；文件夹上传保留层级；文件夹下载为包含空目录的流式 ZIP，不在服务器生成明文临时包。移动禁止移入自身或子目录，同名冲突整批取消。

限制：同名文件不覆盖；上传合并已有目录但不覆盖同名文件；非空目录不能直接删除；删除不可恢复。目录选择器通常无法提交空目录，桌面目录拖放可保留空目录；手机是否可选择整个目录取决于浏览器与系统。上传任务仅保留在当前页面，不支持断点续传；离开页面前会提示尚有上传。批量删除逐项执行，失败项会提示，不保证事务性。

## 更新现有服务器

在本项目目录的 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\Update-Ui.ps1
```

输入 UPDATE 确认，在终端中输入 SSH 密码。不要把密码发到聊天里。

该脚本先验证打包，上传后备份 /opt/private-hub/app/web 和 server.py 到 /opt/private-hub/backups/ui-时间戳，再替换 web 下五个文件，并替换 server.py 以提供移动、目录创建及 ZIP 下载 API。不调用完整安装器，不更改管理员密码、数据库、环境配置、Nginx 或 Certbot。

应用代码改变时需要重启 private-hub，会使现有登录失效并短暂断开 WebSocket；客户端需重新连接。更新前请暂停上传，选择空闲时段。失败自动恢复原有文件；首次增加的未使用 SVG 可留存，不影响旧版。

若自定义门户 /var/lib/private-hub/portal/index.html 已存在，将继续优先显示，不自动覆盖。

## 未来域名 longsiam.space

当前只展示品牌域名，所有功能入口仍为同源相对路径，不跳转尚未启用的域名。正式切换需要单独配置 DNS、Nginx server_name、域名 TLS 证书，并将 /etc/private-hub.env 的 HUB_ORIGIN 改为 https://longsiam.space 后重启服务。仅添加 DNS 不足以完成切换；Origin 安全校验仍然保留，不为迁移而放宽。
