云U盘通信控制台开发者接入

连接你的工具与设备

通过服务端脚本或受信任的本地工具接入 LONGS云。不要将软件 token 或管理员密码嵌入公开网页。

1. 登记软件

进入通信控制台，选择“登记软件”。每个软件得到独立 ID 和 token。凭据只显示一次，请保存到本地环境变量或受保护的配置文件。

打开通信控制台

2. 发送与接收

HTTP 请求通过 Authorization: Bearer <token> 鉴权。启动时先调用 GET /api/software/me 获取自身 {id,name}，SDK 使用 await client.me()；无需手动填写自己的软件 ID。接收方通过 GET /api/software 映射选择。注意 /api/me 是管理员接口。发送消息使用 POST /api/messages，JSON 包含 recipient 与 body；接收使用 GET /api/messages，成功处理后调用 POST /api/messages/{mid}/ack。

POST /api/messages
Authorization: Bearer <token>
Content-Type: application/json

{"recipient":"目标软件ID","body":{"text":"hello"}}

实时接入使用 /api/ws。连接后首帧发送 {"token":"…"}；定期发送 ping，处理消息后 ACK。每个接收方最多保留 10 条未确认消息，满时返回409且不丢旧消息。发送使用持久化 clientMessageId 和 outbox，处理成功后再ACK。不能将中转队列当作永久存储。

安全边界

仅通过受信任的 HTTPS 地址接入。token 泄露时在控制台注销对应软件，重新登记。文件内容是服务器端加密存储，并非服务器无法解密的端到端加密。
