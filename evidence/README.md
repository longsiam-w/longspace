## 证据等级与贡献边界

- **历史原始输出**：导出聊天中保存的工具结果、用户贴出的终端输出；仅证明当时对应条件下的结果。
- **历史交付陈述**：旧助手总结或 Markdown 验收说明；不等于独立重验。
- **当前静态事实**：本次实际读取代码可确认存在的实现；不等于运行正确。
- **用户报告**：按原话记录，不能升级成独立测量。

用户提出自用需求、界面约束、稳定性优先级和租用资源限制；聊天明确显示用户运行部署/诊断脚本、提供错误与使用反馈。大量实现、脚本修改和本地验收由 AI 工具执行。没有证据证明用户逐行编写或完全掌握各模块，不能推断“独立设计开发”或编造 AI 代码占比。Git、聊天和这些笔记均只是过程线索，**不是独立证明个人能力的充分证据**。
